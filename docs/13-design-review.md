# 13｜十二项设计质询及修正

本文件是可公开的设计审查结论，不是开发已完成或真实环境测试通过的证明。

| 质询 | 反例 | 调整与验收 |
|---|---|---|
| 1. 开源个人使用就能任意抓取吗？ | 有账号不等于有分发/保存权 | 代码与来源权利分离，source policy；SEC08 |
| 2. 扫码接口存在就登录体验完成了吗？ | QR返回后会话结束、cookie写失败 | 单会话、保存后核实、重启/注销竞态；AUTH01～09 |
| 3. UI每秒查状态不算爬虫吗？ | 上游 status 会打开浏览器 | 只轮询本地状态；AUTH04 |
| 4. 一次MCP调用就是一次网站请求吗？ | 页面、资源、重试产生更多访问 | 分层计数，未知不是0；RES07 |
| 5. 不看评论只传数量0就行吗？ | 上游0可能归一化成默认数量 | load_all_comments=false，禁止自动展开；RES08 |
| 6. 热门笔记更准确吗？ | 广告/标题党、重复转载挤掉有效经验 | 地域/时间/具体性+多样性，人工支持度评测；QUAL01～06 |
| 7. 全量RAG能消灭重复抓取吗？ | 受限内容不能长期保存，旧价格误用 | 按权限缓存、短期locator不入库；RAG01～06 |
| 8. 单用户可以忽略并发吗？ | 双击、多标签页、旧任务晚到 | 幂等、版本号、generation、单worker锁；JOB01～06 |
| 9. 少请求是否导致攻略很差？ | 为预算凑出三个没依据路线 | 质量底线+缺口输出，不凑数；QUAL07 |
| 10. LangGraph持久化就绝不重复访问吗？ | 恢复重放中断节点 | 工具独立节点、operation ledger，UNKNOWN_OUTCOME；JOB03 |
| 11. 有工程目录就等于容易安装吗？ | Windows用户被要求装Docker/Go | 单独做干净机器发行包验收；REL01～04 |
| 12. 模型能自动把AC换成ABD吗？ | 时长/价格/锁定项漏算 | 确定性校验、差异预览、旧结果失效；PLAN01～07 |

## 仍未消除的风险
真实平台访问稳定性、正常登录的人机验证、用途许可、旅行报价准入、未来日期交通误差、未签名发行包的系统提示，都需要实际运行或外部条件。文档通过不能消除这些风险；如实展示能力状态比承诺“完全自动且永不失败”更重要。

## 后续优化触发条件
当真实使用证明 local vector 查询超过容量/延迟目标，迁移 VectorIndex；当单worker限制可测地影响体验，再引入任务队列服务；当插件通道的安装/权限/稳定性实测更优，再写 ADR 替换而非同时维护两套默认登录栈；当新官方授权接口可验证，再增加 OfficialXhsAdapter，不由名称或传言直接切换。
