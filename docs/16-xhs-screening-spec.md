# 16｜小红书攻略筛选实施细则

## 状态与目标
这是对 04 章和 T04 的实施细化，不是已实现或实测算法。原 76 个应用用例继续 NOT_RUN；新增 SEL01～SEL12 为待实施设计，开发时加入测试矩阵及对应契约、夹具。

目标：有限访问取得能够支撑当前旅行选择的一组互补证据。第一层判断“哪篇值得打开”，第二层判断“正文中哪些内容可用于攻略”。标题相关不等于全文可用。

## 1. 先确定当前决策层级
路线探索阶段：研究区域组合、代表体验、天数范围、移动关系、季节与取舍，不提前深挖餐厅和房型。方向细化阶段：补选定方向的交通、活动、住宿片区及费用。已有 AC 改已有 ABD：先复用仍适用且允许复用的资料，只补新缺口。

预算、人数、交通、实际日期未知时保持 UNKNOWN。系统建议的五天、自驾或两人只能作为显式假设，不能写成用户已确认条件。

## 2. 元信息初筛
只使用已经取得且允许处理的标题、摘要、时间、匿名作者标识。未返回字段标未知，不为完善评分而预读所有正文。

硬过滤只针对明确无关、已确认重复、已知不可访问或明确不适用的内容。七天路线可能包含适用于五天的局部经验，不按标题天数差异直接删除。缺发布日期不是淘汰条件；认证和网络失败不能视为文章不存在。

优先按 note_id 去重，没有 ID 时使用去除敏感参数的规范化链接。短生命期 locator/token 不进入去重持久化键、模型或日志。无稳定标识时记录限制，不编造平台 ID。

## 3. 排序与未知值
初始权重沿用 04 章：相关性 0.35、元信息具体性 0.20、已知约束契合 0.15、时间适用性 0.10、差异性 0.20。这是待校准参数，不是最优性结论。

用户未决定的条件不参与偏好加减分；交通 UNKNOWN 时不能优待自驾。候选自身某字段未知也不等于违反用户约束。

每个维度返回 observed/unknown/not_applicable、实际依据及规则版本。未知值规则必须对候选一致，不能自动填零或满分；具体规则用固定夹具校准并记录。信息完整度与内容匹配度分别显示。

标题详细只代表预期收益，不提升正文可信度。点赞、收藏只能在其他条件相近时弱辅助；不能覆盖相关性和事实核实。不同路线/交通保留合理候选机会；已知同作者通常先读一篇，确需补缺口时可追加。

## 4. 读后验证
提取：正文完整度、实际适用范围、补齐槽位、仍缺信息、来源定位、实际出行时间和待核实事实。

首轮槽位：区域组合、代表性体验、天数/停留范围、主要移动关系、适用季节/日期、取舍理由。

作者体验、可核实事实、系统推断分别标记。“我两小时逛完”不能直接变成所有人的标准时长。开放、预约、价格、道路等硬事实核对适用的权威来源；多数笔记说法一致不能替代核实。

发布时间与实际出行时间分别记录，未知就 UNKNOWN。新发布旧旅行不能冒充最新体验；旧文路线经验可参考，旧报价仍需重查。

仅摘要保持 SUMMARY_ONLY，部分正文保持 PARTIAL_TEXT，不能引用未读部分。关键路线写在图片里时，仅选能补缺口的图像，不自动处理整组图片或展开评论。

商业内容可标记商家自述/利益相关/未知；不能仅凭“私信、推荐、链接”等词断言造假。商家自述不计作独立游客体验。没有实用信息的引流内容降低优先级，判断保留依据。

## 5. 逐篇选择下一篇
不预先并发打开 Top-10。每读一篇更新缺口，按 expected_missing_slot_gain / estimated_visit_cost 选择下一篇。收益以实际可检查的槽位为依据，不用模型“很确信”替代覆盖。

正文使用归一化 hash/相似度聚类识别转载和同源转述。同作者或同源多篇不能虚计独立证据；独立性未知时保留 UNKNOWN。

## 6. 停止原因与完成状态分离
下列为业务语义，映射现有 JobStatus 时同步 Schema/API/测试，不假定这些已是契约字段。

| 原因 | 应有结果 |
|---|---|
| 当前输出有充分依据，关键缺口解决或明确限制输出范围 | 可完成本轮，列明剩余限制 |
| 连续两篇无新增信息 | 重新评估方向；仍有关键缺口则 PARTIAL，不能自动完成 |
| 候选或预算耗尽 | PARTIAL，保留已有结果及缺口 |
| 用户取消 | CANCELED 语义，不能改成成功 |
| 登录验证、限流、拒绝访问 | 暂停该账号，等待正常人工处理 |
| 网络/解析失败 | 有限重试或部分/失败，不当作文章不存在 |

首轮最多 3 次搜索、6 次详情、最多 2 张图是应用成本护栏，不是平台安全阈值，也不保证支持三条路线。证据不足减少方案，不凑数。

失败、重试、双击、恢复和不同节点共享会话预算。用户明确追加有限额度才可继续，模型不得创建新会话规避上限。工具调用次数、导航数与可观测网站请求分别计数，未知不是零。

## 7. 筛选审计
记录设计：decision_id、匿名候选句柄、研究阶段、已观察/未知字段、处理结果、规则版本、理由代码、预计/实际补齐槽位、重复簇、独立性和停止原因。

处理结果至少区分优先读取、暂缓、排除、已读复用。稳定理由代码用于测试，解释文字用于展示。不得保存 token、Cookie、账号昵称、带敏感参数 URL、禁止保存的正文或图片；权限不允许持久化的字段仅限当前运行或不记录。

这些是新设计字段，不表示当前 Schema 已包含。T04 需显式契约变更，不能绕过 additionalProperties 校验偷偷添加。

## 8. 新增测试设计（全部 NOT_RUN）
| ID | 输入 | 预期 |
|---|---|---|
| SEL01 | 交通未知，有驾驶和非驾驶路线 | 不把假设当偏好，保留比较方向 |
| SEL02 | 缺日期/作者/摘要 | 标未知，不猜测、不为评分预读正文 |
| SEL03 | 高热度无关 vs 低热度相关 | 相关性优先，热度不覆盖硬过滤 |
| SEL04 | 多关键词返回同 note_id | 详情最多读一次，预算正确 |
| SEL05 | 同作者/相似转载 | 不虚计独立来源，未知保留 |
| SEL06 | 标题相关、正文无路线信息 | 贡献为空，更新下一篇选择 |
| SEL07 | 只读到摘要/部分正文 | 引用不越界，不标全文 |
| SEL08 | 新发布旧旅行 | 两种时间分离，动态事实待核实 |
| SEL09 | 商家自述和游客体验 | 正确归属，不凭关键词断言造假 |
| SEL10 | 连续两篇无增益，仍缺关键证据 | PARTIAL或改方向，不自动完成 |
| SEL11 | 预算尽/用户取消/验证 | 状态原因正确，未授权后续访问为0 |
| SEL12 | 已补槽位，剩重复与互补候选 | 重算边际收益，审计能解释选择 |

使用合成或有权使用的数据离线回放，不在真实网站双倍执行 Top-10 基线和优化组。分开报告质量、覆盖、引用、重复和成本，不因少请求而忽略质量下降。
