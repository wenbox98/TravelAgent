# 日常私人旅行：一句想法开始

1. 打开本机8768工作台，输入「我想去某地玩几天」，点击「查资料并生成旅行建议」。按钮旁会说明小红书、DeepSeek用途和范围，不需要手填调用次数。
2. 等待页面直接显示资料与可比较建议。若首次模型未配置，按页面完成一次服务端配置；若小红书需要登录，只在打开的官方页面正常登录。网站要求验证或拒绝时停止，不绕过。
3. 查看新读正文和复用历史来源数，展开依据。资料有限时只给有限选择，天数、玩法、交通等缺口保留；不会声称完整攻略。
4. 在「继续聊聊这次旅行」中提问、补充条件；方案卡可以先选方向、排除或撤回。问“为什么推荐这些？”只解释当前引用，不启动新研究，也不改变已选方向。选择方向与采用攻略是两步；需要重做时明确点击「按当前取舍更新建议」。
5. 预览/取消不覆盖原采用版；明确采用后才更新。在「已保存攻略、修改与导出」查看采用版与导出。来源不足可以先用局部建议；明确「继续补充研究」才会围绕缺口启动下一次有限操作，旧用量不重置。

若要用当前旅行已有正文重新分析某个仍存在的缺口，可在继续对话明确发送“用已缓存正文按当前住宿缺口重新分析”，也可明确更低的模型上限。发送前查看用途说明：最多两份有效缓存正文，现有DeepSeek，模型最多8次，连接/搜索/详情/地图均为0；不使用旧许可余额。相同正文、提取版本与缺口已经尝试过则停止，原文已清理、权限撤销或关系无法证明也停止，不自动访问来源补齐。页面分别显示本次新增与此前已有资料；这不是已有回复的本地复核。当前仅通过离线准备验收，真实重新分析尚未实测，本阶段请先评审，不主动继续真实调用。

一次提交按当前需求限定上限：一两天最多连接1次、搜索2次、正文4篇、模型9次；三天及以上或区域旅行最多连接1次、搜索3次、正文6篇、模型13次。模型包含必要提取与审核，不是承诺都会调用。材料覆盖足够时只需1次规划模型及零站点访问；仅有一项活动或非空缓存不算充分。失败也计数，不自动重试、不继承其他旅行额度。展开「研究进展与资料依据」可查看真实尝试、成功正文、新查/缓存及缺口。次数上限不是费用承诺。

本轮新链路通过合成离线验证，最新真实小红书整链仍待独立验收。只分析可读取的文字，图片和视频未分析。不要把标题、模型审核或材料覆盖充分当作实际可行性已经核实。当前对话解释基于本地引用和有限条件解析，并非任意话题的模型问答。

## 从新旅行开始

1. 点击“新建独立旅行”，用一句话填写这次想法，然后点击“开始规划”（或 Ctrl/⌘ + Enter）。明确提到的目的区域和天数会在下一步显示；识别不清时可展开修正区域。人数、交通与开始时刻可未定；不会继承旧旅行偏好、预约或额度。
2. 在“先用已有资料”选择一条路径：浏览“我的旅行资料”并加入卡片，或选择同目的地、同旅行类型的历史采用组合。开发测试资料默认隐藏，只有明确勾选才显示。看到零候选时可调整筛选或整理已有资料，不会自动换城市或联网补齐。
3. 历史活动先进入可取消的本地草稿。展开“查看或修改选材”可查看来源；下方比较项目、停留建议与整体背景。历史 AI 停留不是实测，也不是本次重新生成。旧日序仅作历史参考，新草稿日序从第 1 天开始，可按本次天数自行调整，未覆盖的天数明确保留。
4. 可以取消恢复选材前状态，重新选择；满意后明确“采用”。已有非空草稿不跨类型覆盖：继续改变当前组合，或另建独立旅行。选材后区域自动收起，修改入口保留。
5. 采用后“导出 Markdown”，得到与页面采用版同源的文件。未采用预览不覆盖旧版。刷新和正常重启恢复选择，不重新调用模型或地图。

## 需要新资料或新建议时

当前普通首页可直接写下想法，点击“查资料并生成旅行建议”；继续对话用“发送”。这次点击按页面用途创建有限V4许可，无需填写技术额度。先模型理解，再按资料缺口从同一搜索列表择读多篇、严格审核并生成可选择建议；新许可首次模型最多13或18次，普通后续最多8次，搜索/正文仍分别最多2–3次/4–6篇或1次/2篇。每篇读取前保留后续决策与生成空间。旧许可和失败不自动补额；缓存足够可跳过站点，问题/假设只从缓存回答而不改变条件。

高级“查找新玩法”入口与本地选材分开。只有你确实需要独立外部研究、AI建议或地图时，才在本次旅行设置有限操作许可，核对接收方、资料范围、用途和次数，再主动点击对应操作。配置存在、打开面板、保存和刷新均不等于授权。

没有许可、许可关闭或额度耗尽，仍可本地浏览、复用、预览、取消、采用和导出。失败/超时不退回已派发次数，不自动重试，不转用旧批次余额。本轮交接验收没有建立非零许可，也未发起旅行业务外部请求。

## 修改、历史与失败

入口明确显示正在连接、需要重新打开、本机离线或其他错误。未提交想法只保留在当前浏览器本机，刷新及恢复连接后仍可继续；提交成功后清除这份未提交副本。该保护不等于所有活动编辑均已耐久保存，看到未保存提示时先保留页面。服务已运行时重新打开入口不会取消任务、重置额度或重新派发。

“改变组合”可预览本地取舍，取消恢复原草稿；明确采用形成新版本，历史采用版保留。普通“恢复已采用版”恢复当前旅行最近采用的版本。“历史旅行与合成场景”可回到原旅行；另建旅行的历史组合选择可查看仍有效的旧采用版本。不提供任意旧版本一键覆盖当前旅行的操作。

网络失败或模型提议被拒时，原草稿与采用版仍在。查看页面“依据与诊断”和提议拒绝原因；可安全复核的旧回复会显示“本地复核”入口。没有该入口时不代表应重新请求模型；诊断可能过期或不支持复核。不要把 Key、原始响应或私人导出上传求助。正常退出不会自动重试。

## 资料与能力边界

- 知识库当前为本机关键词检索，未实现向量检索；知识卡、地点提及与采用节奏是不同资料性质。
- 清原文缓存保留已整理知识、历史记录与账本；删除知识禁止后续引用，旧采用版仍保留。清理均需独立影响预览和确认，不退出登录。本轮未删除主库原文。
- 原文已清理的历史资料通过仍有效的知识卡复用，不偷偷读取备份或绕过卡片版本校验。知识卡形成的历史安排也需走资料卡入口。
- 来源片区背景保留条件与作用范围，不能当作每站确定特色。明确要求市区时，范围未知仍待确认，不能当作匹配。
- 已有有限资料可以给出有限建议，不要求每站百科齐全、精确钟点或每天排满；空白不算完整建议。
- 开放、预约、实际交通、价格与新目的地攻略质量不因入口通过而得到保证。地图需要主动核实，临时值重启失效，不自动重查。
- 费用中的 AI 数字只是预算预留，不是报价；未知不当零。尚无酒店预订、供应商报价或整趟可执行性保证。

本轮只交付私人试用候选。请按自己的兴趣评判资料相关性、玩法帮助程度和取舍是否合理；后续以实际遇到的具体阻塞为修复范围。
