## D2 v0.1 个人工具
G0～G4 通过，且以下人工脚本执行并记录：启动→配置模型→连接小红书→输入模糊需求→看到有来源的路线方向→补充时间/交通→查看细化→AC改ABD→预算变化→资料复用→退出/重启→断开账号。

票价通道允许某类别不可用，但该类别必须清楚显示未知、预算不完整，不宣称“已查携程/已比价”。高德不可用时不通过 R09 对应的 D2 门禁。

## 发布清单
版本号、源码 commit、依赖锁、sidecar 上游 commit＋patch hash、构建产物 hash、平台支持范围、真实能力矩阵、测试报告、未验证项、许可证/NOTICE、隐私和数据说明、诊断指南、卸载与数据清理说明。

样例截图只能用合成数据，或拥有明确权限的资料；截图中必须区分演示与实测。不要附赠公共小红书数据集、cookies样例、真实xsec_token或含账户头像的二维码。

## 暂停发布条件
凭证泄露；可以调用写工具；正常注销后会话仍可能复活；无限重试；将缺失价格显示0；旧任务覆盖新版本；引用不可回溯；来源权限不明却共享全文；硬约束冲突仍被标可行；未签名包被描述为已签名可信发行。

## v1.1 XHS PoC 额外门禁
在 G1 通过前，至少执行并记录以下场景：缓存证据足够时 0 次 XHS 搜索/详情；同 source 多次命中只读一次详情；证据提前满足时不消耗剩余预算；追加“五天/不自驾”只补 Evidence Gap；登录失效或 verification 后 0 个未经授权的新访问；SUMMARY_ONLY 不得显示“已阅读全文”；旧 revision 的晚返回不得覆盖新计划；预算耗尽返回 PARTIAL/insufficient_evidence 而不是继续请求。
