# 缓存路线参考、单次问答与关键路段契约

本契约补充普通首页的一次提交编排，保留原研究、逐条上下文审核和建议型规划标准。没有合格具体活动时，已采信的宏观路线仍可供用户比较；不能由此制造活动、独立来源或现实可行性结论。

## 路线参考

`reference_overview.references/project/derive/view/export` 只读取当前旅行关联资料和已选知识的合格引用。要求已有审核性质、作者角色与定位；不搜索全库同名目的地兜底，不读取待审或拒绝候选。按来源分组，至少有 ROUTE 才形成卡片，保留原文、条件、时长范围和已证明的路线对象关系；同源不等于条目间存在关联。

`derive_overview` 是显式本地派生，保存规则版本、完整输入指纹、父任务及递增版本。选择、撤回和重选通过原 conversation revision/version 校验；草稿、绑定或规则变化使旧投影失效，旧历史不覆盖。旧自动任务的 BLOCKED 结果不改写。后续自动研究无具体活动但存在合格路线时，允许生成 LOCAL_REFERENCE_OVERVIEW/PARTIAL，仍不生成或采用攻略。

`GET /api/v1/preview/planning/{session_id}/reference-overview-export` 只导出当前有效的独立本地参考。文件名 `route-reference.md`，明确不是采用版；采用版攻略导出契约不变。GET、刷新和恢复均不派发任务。

## 一次缓存问答

主输入框提交 `ConversationAction.ask`，携带 `PRIVATE_CACHED_QUESTION_V1`。按钮旁显示一次模型调用、必要缓存引用、接收方 DeepSeek、每来源6000字及无自动研究/重试。旧本地解释入口仍保留并标记 LOCAL_REFERENCE_EXPLANATION。问号不再吞掉明确陈述的约束；假设性提问不自动改行程。

`questions.payload` 冻结当前有效选择/排除、最近过滤后的用户意图、天数/交通/节奏、已知预算和硬时间条件，以及至多两来源的最小合格引用。引用保留主题、时长范围及已证明的路线对象文字/作用范围，不由同源关系推断。逐条执行现有 SourcePolicy 与外发过滤，文本、条件与必要关系文字合计每来源最多6000字。无完整正文、BodyBlock、私址、凭据、地图返回或助手解释作为新事实。无合格引用时允许明确不足的建议，不能声称已核实。

新增 QUESTION 用途沿用 `research_continuations/continuation_operations/preview_jobs`：显式新许可最多模型1次，与旧许可和历史用量关联；保存状态和预留在同一事务，重复幂等键不重复派发。`answer-worker` 最多一次 HTTPS 请求到既有 api.deepseek.com，模型超时120秒、外层180秒，不调用研究或地图，不自动重试。

任务领取一次；派发前后检查许可、账号、旅行、请求版本、当前 job 和重新计算的输入指纹。条件、资料或选择变化后晚结果不能写回。重启取消未完成任务并关闭本次许可，不恢复次数、不重新请求。失败只存安全原因码。

`Answer` 是有限建议、允许集合内的引用 ID、缺口与待确认条件解释。程序回填引用，回答标 AI_CACHED_ADVICE，不入 Evidence、不采用攻略。`confirm_intent` 是单独本地动作，绑定回答时草稿指纹，继续原锁定项及约束检查；减少天数只整理未锁定日序，旧采用版不动。

## 一段公共路程

`POST /api/v1/preview/key-leg/{session_id}` 使用 `CriticalMapAction`，继续同源鉴权、CSRF、revision 和幂等回执。`critical_map.view` 只投影当前顺序中同一天、相邻且各自有来源依据的两个公共活动；宏观路线不拆成景点，不要求其他无关项目均具备依据。不推断家庭起终点，不因未采用攻略阻止核实。

用户明确交通方式、所选顺序和 `PRIVATE_KEY_LEG_V1` 后，建立本次 MAP 许可，最多地点2次/路径1次。模式不得把驾车参考冒充公交；缺 Key 只显示待配置，不探测。首次动作可连续查询两个必要地点，第一处失败立即停止；地图返回的实际 POI 必须由用户确认，这条路径不按名称自动确认。

路径必须再次显式点击，只查所选一段及适用日期参数。I/O 前持久化意图回执，重复提交、刷新或重启不续执行失败/部分请求；旧调用不退款。地图结果、坐标、供应商标识不写数据库，重启结果过期；保留选段、用户输入、许可与用量，需要新点击才能查询。参考不保证接驳、班次、停留或未来可行性。
