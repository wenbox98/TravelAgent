# P04 本机旅行流程与规划建议

P03.1 之前的五天、不自驾、包车、日期与端点均属于用户配合的历史测试，不是长期偏好。历史记录保留，新旅行不复制它们。G0 历史结果不变，G1 仍 NOT PASS，G3 不升级。

## 流程与数据

现有 Vue App 新增渐进规划视图，原缓存页面保留为历史资料入口。方向、活动、条件、时间草案按阶段展示，确认后折叠；方向改选可单独取消，保留其他偏好。普通字段 change 自动保存本地草稿，整体显式采用/恢复。UI 折叠写在当前会话，不递增内容 revision，不让展开行为使建议失效。

`PlanningService` 复用 `preview_sessions.state_json` 和原回执；不建立新的旅行权限或偏好数据库。新建目的地与 `research_questions.request_json.destination` 精确匹配，多匹配/未匹配保留缺口。不重新提取、不把旧资料换城市标题、不把研究时的条件复制成新旅行默认值。真实资料只由既有严格 PreviewService 投影进入候选，引用及条件保留；合成活动在 SYNTHETIC_DEMO 会话中，与真实 Evidence 分开。

`TripInputs.mode` 默认 UNKNOWN，`same_return` 默认 true（可修改的产品假设），范围默认 ACTIVITY_WINDOW。历史已经保存的 mode/same_return 原值保留。新增 `PlanDraft` 单独持有用户交通意向、驾驶意愿、活动时间与相对日；地图枚举不等于用户偏好。AI 的交通比较留在提议中，不静默写入偏好。

缺少 planning_scope 的旧 P03 行按原 DOOR_TO_DOOR 语义读取，不在 GET 时改写数据库。新草稿最多 12 个活动，与现有地点契约一致；大小写不同的重复活动 identity 同样拒绝。

## 地点与时间

`RoutePreviewService` 复用已确认 origin identity 给逻辑 return；只显式 same_return 才复用，不按相同字符串合并车站和城市。逻辑往返边保留，两个方向分别计算。端点改变只让涉及它的已有边失效；模式/适用日期改变使相关旧参考失效。`PlaceChoices` 是原路程面板与新流程共用组件：确认后收起其他候选，重选只用内存；唯一地区/类型/名称匹配可标推荐，仍需用户确认。

本批新流程真实地图能力关闭，旧 P03 剩余 3 地点/6 路径仍留在原授权，不能移到新行程。`FlowMapService` 复用原 identity、迟到保护和相邻路段实现，仅给显式合成会话注入自编适配器。真实会话不能执行合成查询；合成返回醒目标注，不持久化、不发往模型、不计作高德实测。

活动窗口从首项或锁定预约开始；合法已知移动 + 活动停留范围 + 明确休息顺序计算。未知移动/停留/休息使后续精确时刻中断，前面的可用安排仍显示。固定预约不改写，冲突单独保留。自行到达不要求家庭地址；最晚到家硬约束仍显示为未核实，门到门可单独开启。地图估算、AI停留建议、用户输入和未知分开；无全程可执行承诺。

首项时刻/时段只适用于指定的 first_day，不自动复制给第二天。道路参考即使已有返回，也只有与当前明确交通意向相符时才可参与条件时间计算；查看 DRIVING 不能填充 PUBLIC_TRANSIT、UNKNOWN 或尚未落实的当地服务安排。日期修改使旧路段参考失效。

## 模型任务与契约变化

新增 `planning_suggestion` 独立提示词与 `PlanningResponse`，不套用抽取逐字要求。输出活动 ID、日序、停留/休息、首项时间、简短理由、引用、假设、未知和影响；程序回填活动名并校验 ID、日数、预约、锚点和明确交通意向。提议先放入草稿，整体采用才变更确认版。建议不成为来源事实或作者亲历。

`preview_jobs` 复用原状态、取消、幂等键与耐久预算，迁移 015 仅把“每 continuation 一条研究 job”的索引限定到非规划任务；不改动旧行、不改旧状态/审核/预算，不增加表。内容 revision 不匹配时拒绝旧建议，取消/180 秒外层截止先标终止再关闭独立模型子进程；120 秒 provider、单次 HTTP、无自动重试。重启只标中断，不重派发。

同一进程内每个 job 只启动一个监督任务，回放相同请求不会由第二个监督任务误标正在工作的任务失败。服务正常退出先使未完成 job 失效，再终止自己启动的子进程；不操作其他服务。模型出错、启动失败和超时保留原草稿，不返还消耗额度。

本次独立且固定的 `p04-planning-synthetic-two` 许可最多 2 次、城市/区域各一次。通过明确 operator 命令登记，启动/GET/新行程不会创建或恢复额度。只序列化服务端自编虚构活动、枚举、数值和时间；拒绝更名活动、真实来源、任意正文/地址；原 Key、模型、地址和 120/180 配置绑定。普通私人新行程本批不能触发外部建议，仍可编辑本地草案。

API 位于原同源鉴权边界下的 `/api/v1/preview/planning`、`planning/{session_id}`、`planning-maps`。GET、刷新、条件变化、采用和折叠零外部调用。Schema、OpenAPI 与相关测试同批更新。

## 服务与恢复

唯一推荐入口 `scripts/product_preview.py --open`，默认 8768。首次从原 P03 库做 SQLite 一致性备份到 `.local/p04-preview`；原库与 `.local/p03-web` 均不覆盖。迁移前另保留备份。独立 `.local/p04-web` 静态目录。服务端审计阻断小红书/高德外连，模型 worker 仅允许既定 DeepSeek HTTPS 单请求。

旧 P03 只在确认 PID/命令后正常停止；回滚先正常停止 P04，再用 `scripts/route_preview.py --open` 启动原库/原静态目录。不会复制 P04 的选择回旧库，不批量结束其他页面。临时地图重启过期，活动/采用/折叠/预算持久恢复。
