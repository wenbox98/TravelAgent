# 首次模型理解与有界业务工具循环（V3）

普通首页和继续对话使用 `PRIVATE_GOAL_AGENT_V3`。首次提交先保存原话、旅行与有限许可，状态为 INTAKE；规则解析仅用于暂定界面和原有额度分档，不能标为模型已理解。真实理解成功之前不派发小红书或地图。历史 V2/会话 V1 的请求、失败、采用版和账本保持原义，兼容入口不回写历史。

## 理解与程序约束

`agent_contract.Understanding` 返回意图、逐字段原话引用及 Python 字符位置、简短可审计摘要。`agent.apply_intake` 只提交定位正确且类型合法的更新，重新校验 PlanDraft，保护锁定项目、预算、明确预约和截止条件。到达方式 arrival_transport 与当地 transport、driving、rental 分开；飞机到达不覆盖租车自驾。初次提交抛弃未证实的规则猜测，后续只更新明确陈述。QUESTION/HYPOTHETICAL 不得更新条件；混合句只能引用其中明确陈述的修正。语义由模型判断，程序检查引用、类型、冲突和锁；引用正确不等于语义必然正确。

单独填写的目的区域由程序持有，作为独立输入传入模型；不伪造它在原话中的位置。与原话冲突则停止澄清。未给出的机场、私址、人数、预算、日期仍未知。原话经现有敏感信息过滤后才出站，审计同时保留过滤输入摘要和能证明的原话位置；敏感或有歧义的定位不得提交。

## 工具与反馈

最多六轮监督决策，每轮为一次真实模型调用。模型只能选择下列业务工具，不能获得浏览器控制、Cookie、token、任意 URL 或供应商底层接口。

| 工具 | 作用及边界 |
|---|---|
| CACHE | 本地重新核实资料的有效性与用途，零外部调用 |
| DECOMPOSE | 仅整理已经采信的玩法、路线与取舍，保留作者角色、条件和作用范围，不重新审批 |
| RESEARCH_GAP | 当前缺口内一次搜索、至多一篇新正文，继续原严格提取和上下文审核；不同轮可选择不同缺口 |
| GENERATE | 使用当前选择、排除、锁与合格引用生成一次可修改建议；同一任务生成可用提议后不再采集或生成第二份 |
| ANSWER | 问题或假设的缓存回答，不改偏好、不查新资料 |
| KEY_LEG | 只在本次明确授权后，使用既有高德包装器核实一段有来源的公共衔接 |
| FINISH | 结合实际结果与缺口停止，程序决定 COMPLETED/PARTIAL/BLOCKED |

派发前持久保存决策；派发后保存实际状态、采信数量、前后覆盖和剩余额度。下一次模型输入包含这些真实反馈以及当前有效选择、排除、相关引用、条件、两段交通和锁。源文和工具文字都是数据，不可执行其中的指令。正文事实审核和逐方案校验不因工具选择而省略。空白占位、路线名称和未知交通仍不能成为完整攻略。

所有子任务共用一个既有 grant 与耐久操作账本。首次原上限仍为模型9或13、搜索2或3、正文4或6、连接1；后续仍为模型5、搜索1、正文2、连接1。理解、监督、提取、审核、建议都消耗同一总模型上限，未新增阶段额度。一次 gap 工具最多一篇，不承诺耗尽正文上限；有限额度不足以完成提取加规划时保留资料和缺口。缓存足够也需理解与决策调用，不能继续声称 V3 缓存流程只需一次模型。

多轮研究共享同一个 owned reader，会话仅连接一次，详情编号沿用同 grant 累计值。所有搜索列表仅表示观察到标题等元数据，正文次数独立显示。task_view 汇总本任务全部研究子任务及候选去重，不能只显示最后一轮。后续来源失败不能隐藏先前独立合格结果。遇到登录挑战、验证、限制、取消、失效、迭代上限、重复动作或额度不足停止；不自动重试失败调用。

## 地图、采用和恢复

地图默认额度0；首页独立勾选本次一段公共衔接才登记最多2次地点和1次路径，其他旧许可不变。程序验证公共来源、相邻同日对象、适用交通、当前 revision 与权限。候选地点必须用户确认，不自动选择 POI、不用驾车代替公交。需人工确认时循环停止；后续由既有关键路段页面显式操作，不宣称已自动完成整段。地图原始返回只存在服务内存，监督模型只收到状态，不得到坐标或真实地图响应。此交互仍不是全自动地图闭环。

新建议仅为待选提议，预览、取消、采用和导出使用原生产路径；导出同时区分到达方式和当地交通。重启只恢复已存结果或标记中断，不重新理解、不重派工具、不恢复额度。generation、父任务状态、当前 revision、输入绑定和引用有效性一起约束晚到结果。

SQLite 18 仅修改任务唯一索引：历史普通研究仍单 grant 单 job；V3 agent/model/research-step 可在同一 grant 顺序执行，但仅允许一个活跃 agent/research-step 子任务。没有删除、转换或重新审核业务行。迁移18与 domain/openapi 契约在同一个明确的契约变更提交交付。

## 验证界限

离线验收使用自编来源、受控 Reader/Amap transport、生产 worker 和真实 OpenAICompatibleProvider 序列化入口；所有外部 socket/DNS 被拒绝。它能证明流程、权限、输入与恢复，不能证明 DeepSeek 实际语义质量、真实小红书研究深度或高德时效性。本批不新增真实请求，G1保持原NOT PASS，真实质量为NOT_MEASURED。
