# P06 采用版改选与受限诊断

在既有 PlanningService、preview_jobs 和 continuation_operations 中扩展，没有新产品入口、权限系统或数据库迁移。数据库 schema 15 不变，主入口仍为 `scripts/product_preview.py --open`，8768。新页面构建到 `.local/p06-web`，旧构建和采用版保留。

## 协议 3

新 `RevisionResponse / RevisionProposal` 仅允许已有活动 ID、日序、停留下界/上界、休息、引用 ID 和 LONGER_FIRST/FEWER 理由代码。严格拒绝额外字段、文字指令、URL、新地点、未知引用和类型转换。固定首项时间、交通、往返范围、截止及预约仍由程序输入持有。模型比较安排与取舍；程序按结构生成标题、差异和缺口，不把模型自由文案作为执行依据。

协议 1/2 的历史输出、失败和采用版继续原义读取，旧判定不自动重跑。旧规则对“开放时间：未知”的误判已经离线复现，但不能推断 P05.2 历史失败的具体句子。P06 使用独立协议解决当前路径的问题，没有继续扩充旧规则关键词例外。程序生成的未知项不再需要通过模型自由文案正则。

本批不启用新的自由说明通道：未经声明的说明字段会拒绝相关方案，其他独立合格方案保留。URL/认证材料等共享安全污染整次阻断。说明隔离计数为 0，不把删除说明后的旧失败自动转为成功；条件依赖不明的旧输出不导入协议 3。

## 基准、意图与采用

发起必须以已有采用版为基准，普通未采用编辑先保存本地，不静默丢掉。输入保存业务快照、base_revision、采用版版本和摘要；只发必要公开名称、定位过的提及与过滤条件，每来源每次最多 6000 字，没有地图值和私址。

- LONGER_FIRST 锁定发起时第一项 ID 和完整活动顺序；只允许目标停留两个界限同时增加。具体增量须精确一致；未指定时增量限 5–120 分钟，属于可修改建议。其他停留、休息和日序不得变化。
- FEWER 恰好减少一个未锁定项目，保留剩余活动的顺序、日序和全部时长；预约锁定项不得删除。首项 10:00 约束不等于锁定首个活动身份。仅剩一项或全部锁定时不可发起。
- 继续复用引用、范围、预约和截止检查；未知交通不会填零或引用已过期地图值。未知交通仍意味着未证明到达时间。
- 预览只写草稿并保存预览修订及摘要；取消恢复完整采用版，再次预览同一已存结果不调用模型。采用前复核采用版版本、来源、固定条件、修改意图、当前预览修订与摘要。其他编辑会解除 AI 预览标记并按原规则记录人工修改来源。
- `adoption_history` 保存此前采用版，`adopted_version` 防止旧提议覆盖后续采用；幂等与数据库事务沿用原实现。worker 从不直接写采用版。

## 有界调用

唯一追加许可 `p06-adopted-revision` 绑定旧 P05.2 旅行、内容快照和采用版摘要。项目模型最多 2；XHS 和地图全部为 0。首次限定 LONGER_FIRST；首次成功且其真实提议已采用后，可用第二次 FEWER。旧批次记录不变，重启或换旅行不恢复预算。失败默认停用；剩余复验须有明确代码修复和专门登记，不是自动重试。

120 秒模型等待、180 秒外层监督沿用。主入口的出站防护在本批只允许规划 worker 访问原 DeepSeek；serve、研究 worker、提取及审核角色不能访问高德、小红书或模型。许可与余额仍在派发前耐久预留。

## 诊断与本地回放

主页面只展示 job/方案号对应的安全摘要、字段路径、校验步骤、规则版本、引用/约束/未知类别、返回/解析状态与计数，不显示被拒原句。差异来自结构比较，不能复制模型声称的增量。

受限文件位于活动库旁 `planning-diagnostics`。只保存尺寸/类型/字段白名单内的结构提议及业务输入摘要、job 引用、base_revision、协议/规则/模型配置摘要。引用原 preview_jobs 中的业务快照，不复制必要性以外的源文。记录摘要与任务绑定，篡改、跨账号、过期或清理后均不可回放。不保存 HTTP 原包、headers、reasoning_content、凭据、任意 URL 或真实地图返回。不安全/无法过滤的提议只留不可回放摘要。

默认 7 天有效：回放读取检查有效期；启动清理过期文件。独立清理不删除原文、Evidence、任务结果、采用版或账本。这个保留期是工程默认，不代表法律许可。

```powershell
# 只读原输入并另存版本化本地复核，不联网、不收费、不自动采用
.venv\Scripts\python.exe -X utf8 scripts\product_preview.py diagnostic-replay --job <本机任务编号> --code-sha <当前完整提交SHA>
# 清除过期记录；加 --all-records 仅清除全部受限诊断
.venv\Scripts\python.exe -X utf8 scripts\product_preview.py diagnostic-clean
```

回放明确标为 LOCAL_REVALIDATION，绑定原输入与旧规则，另存结果，旧模型判定不修改。P05.2 缺失的原响应不从报告补造。缓存浏览、保存、预览、取消、采用、查看诊断、刷新及重启全部零外部调用；地图过期如实展示。
