# P05.1 范围与程序持有的规划条件

沿用 8768、P04 活动库和原独立旅行，静态构建写入 `.local/p051-web`，历史 P05 不迁移为成功。历史门禁不变。

## 范围

`PlanDraft.spatial` 区分 CITY_CORE、CITY_AND_SURROUNDINGS、REGIONAL、UNDECIDED，并保存条件来源。城市名不自动代表中心城区。Activity 的 region 是 REQUEST_FILTER；source_locations / spatial_basis 是审核引用中的来源描述，不是地图观测位置。标题仅 TITLE_WEAK；逐活动明确正文/条件支持才可 MATCH，冲突或不明保留 UNKNOWN。无城市名单、中心点或半径硬编码。

当前市区草稿不能自动选取范围未明/不匹配活动。不匹配项折叠为周边备选；旧采用版保留。普通研究将活动范围缺口加入停止判断，只有两个 MATCH 才满足市区数量早停。来源数与活动数分别统计。来源对范围的表述不是外部地理核实，地图行政市一致也不自动升级范围。

## 安排协议 2

输入保留交通、步行许可、首项时间、锁定日序/预约、硬截止及同 revision 的 Evidence。新 `ArrangementResponse` 仅输出活动顺序、停留/休息、理由/取舍。未知开始/交通可提出独立未采用建议。程序合成固定条件，标 PROGRAM_INPUT；停留和休息标 AI_PROPOSED。旧 PlanningResponse 继续可读。

提供模型完整 schema；本地先校验顶层结构及全局安全，再对每个提议完整验证。无效公共目录只阻断依赖它的提议。非法字段/引用、隐含自驾/包车、改动锚点、时间冲突分别拒绝，不重贴交通标签救活方案。稳定 proposal_id、规则版本、输入摘要、枚举诊断及通过提议存入原私有 job；不保留完整响应或隐藏推理。

部分接纳为 PARTIAL，页面展示独立数量及原因。采用之前重新核对 revision、政策、引用、范围与固定输入，任何新条件都不被旧提议覆盖。未显式采用时原确认版不变，恢复不重新派发。

## 时间与额度

内部保留接口秒数和原区间；一般显示向外取整至五分钟并带“约”。首项锚点/固定预约原样显示。未知交通仍未知，休息不抵扣或替代交通，不增加拥堵倍数。

新批次 `p051-scope-locked-planning` 关联 P05：连接/搜索/详情 1/1/2、模型 5、地点/路径 5/3。旧批次与失败记录不可变，首次使用绑定独立旅行。两次提取是批次上限、同一来源不重试；读取详情前检查至少剩余三次模型额度，为提取、审核、规划保留容量。研究最多用四次，至少留一次规划。原 DeepSeek 120 秒响应 / 180 秒总截止，无连接测试或重试。

GET、刷新、编辑、预览/取消/采用及重启不外连。地图只在显式动作时读取公共活动，不进入模型或持久存储，重启显示临时参考过期。真实验收状态见本批报告，离线用例不能替代真实通过。
