# 日常私人工作台：显式许可与资料复用

同一 `scripts/product_preview.py --open`、8768、当前活动库。普通旅行由服务器标记 DAILY；测试标记只描述输入用途，不带额外权限。历史 P04–P06 入口、协议、许可、失败和用量保持原义，不被普通操作回退使用。

## 许可与账本

普通页面通过 `PlanAction.authorize` 提交 `OperationAuthorization`：用途、调用上限、有效小时及明确确认。ID 由服务器随机创建，不接受客户端指定 provider、scope、continuation 或数据库路径。许可绑定本地账号、旅行、目的地、所选资料/活动范围、任务类型、固定接收服务与当前配置摘要、工作区摘要和期限。

复用 `research_continuations / continuation_operations / preview_jobs / preview_receipts`，数据库 schema 15 不变。新增字段存在原 JSON 状态中；没有新的阶段批次常量或权限平台。增加 `OperationAuthorization` DTO，`PlanAction` 增加 authorize、revoke_authorization、reuse_activities；`PlanView` 增加 operation、model_status 和 reuse_options，沿用原同源鉴权、CSRF、修订与幂等键。

每个许可有硬上限：模型最多20、搜索3、详情6、连接1、地点16、路径16，有效期1–168小时。地图响应的总额与已用合计是0–32内的整数，不再枚举历史批次固定总额。它们是产品配置边界，不代表本次 Work 的实测授权；Work 仍服从当轮更低的具体上限。未明确点击授权不产生许可；新旅行、GET、刷新、重启和模型输入均不能创建许可。配置有 Key 不代表允许使用。

明确追加创建新记录并关联前许可，同时关闭前许可的未来派发，未用次数不转移；原上限、消耗、失败、配置和输入摘要不改写。页面展示每条历史、累计已用与当前可用。撤销只关闭未来派发并标记未完成任务取消；已发送请求无法保证撤回，失败、超时与状态未知不退还已派发计数。不声称供应商计费或绝对一次执行。

操作发出前在 SQLite 事务中占额；重复键、并发旧修订和已领取任务不能重复派发。正常改选没有两次总限制或固定先后顺序：先减少、后延长、第三次合法改选由余额决定；一项不能再减少等业务检查仍在。历史固定批次保留原限制。

## 资料、模型与地图

普通新旅行不按同名目的地自动挂载全部历史资料。页面可明确选择同账号、同目的地、同旅行类型的历史采用版本及活动，复制所选资料依据与已有停留建议，不复制采用状态、旧额度、交通、首项时间、包车意向或预约。界面标记既有建议，不能冒充新模型生成。

复用时和后续模型/采用前核对来源 policy、有效期、引用与发现定位；新旅行内保留 SOURCE_MENTION、SOURCE_REFERENCE、AI_PROPOSED 等独立属性。地点身份曾匹配不是当前地图值、市区匹配或作者经历。无匹配资料保持空项目和待研究方向，不回填合成活动。

规划与改选继续原 payload 过滤，每来源每次最多6000字；模型目的地址固定为配置中的 api.deepseek.com，不含私址、认证材料、地图返回或隐藏推理。首次规划沿用协议2，局部减少/延长沿用 P06 协议3、独立检查和结构差异；固定条件仍由程序持有。

研究复用现有 ResearchService、v3提取和独立上下文审核，分别计入 MODEL；详情前至少保留提取、审核和最终规划所需的3次余额。首篇待审不永久锁死旅行，下一不同来源可在同一许可和余额内继续。旧任务不自动重试，新明确动作仍受当前许可、资料范围与去重限制。

地图复用原服务端适配、候选确认、相邻采用方向和临时内存结果。按实际 MAP 许可与额度启用；公共地点之外的私址仍不在当前许可范围。地图结果不持久化、不发送模型；重启过期，不自动重查。驾车参考不能替代公共交通，未知交通不算零。

## 出站与晚返回

读页面、本地修改、采用、恢复不外连。入口安装原角色白名单：只有规划/提取/审核 worker 能调用固定 DeepSeek 路径且单进程一次 HTTP；只有经过地图传输上下文的主服务可以访问高德四个既有路径；研究 worker 才可构造受预算保护的只读浏览器流程。页面和模型不能切换角色或接收方。没有把 network.install 改成全允许。

worker 派发前验证用途、许可、来源、任务状态和修订；提取、审核与规划在潜在长响应后再检查。撤销、过期、变更修订或任务取消后不发布晚到结果，不覆盖采用版。地图响应也再次检查当前许可和输入代次。保留失败与消耗，正常关闭/重启只标记中断，不重派。

本批真实小红书访问为0；普通研究组合只用合成适配器验收，不把它标成新的实站通过。历史门禁分别保留，不因日常入口接通而升级。

## 启动与恢复

默认继续 `.local/p04-preview/preview.sqlite3`；静态目录 `.local/workbench-web`，运行计数在活动库旁 operation-audit。正常启动不需要阶段参数或命令行授权，首次有模型/地图动作前在页面确认用途与上限。

```powershell
Set-Location E:\workSpace\travel-agent-project\travel-agent
.venv\Scripts\python.exe -X utf8 scripts\product_preview.py --open
```

可通过 `--account-scope`（或 TRAVEL_ACCOUNT_SCOPE）配置本地账号，通过 `--workspace` 显式指定目录。后台子任务继承实际数据库目录，不回到固定历史目录。真正空白目录可初始化，不依赖任何旧 Pxx 记录或先前私人库：

```powershell
.venv\Scripts\python.exe -X utf8 scripts\product_preview.py --workspace .local\my-private-workbench --account-scope my-local-account --initialize-empty --open
```

已有配置目录缺失数据库、数据库损坏或未知模式立即报错，不从旧库静默重建，也不拿空库冒充恢复。当前历史库、profile、旧静态构建和备份保留；不能覆盖当前库恢复耗尽额度。
