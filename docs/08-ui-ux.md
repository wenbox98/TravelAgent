# 08｜页面设计与交互验收

## 页面清单
Setup：环境与模型配置、连接小红书、高德能力提示。
TripWorkspace：对话、粗略攻略、地图、每日安排、预算、当前研究来源状态。
Knowledge：可复用资料、来源/日期/保存条件、个人选择历史、删除。
Settings：账号断开、模型/地图/报价能力、隐私开关、诊断导出。

## 首次连接页面
标题“连接你自己的小红书账号”。说明：使用官方登录页面，在本机保存专用会话；不收集密码；可能需要平台额外验证；可随时断开。

主按钮“连接小红书”；成功后展示“已连接，最近核实于…”。状态过期提示“需要重新确认登录”，不是“账号被封”。验证码/安全验证显示“请在官方窗口完成验证”，按钮打开本机窗口。

二维码与等待状态独立；倒计时结束只显示“二维码可能已失效，点击刷新”，不自动无限刷新。双击、返回、切页不创建多个登录上下文。离开页面只停止本地 UI 订阅，不默认撤销正在等待的登录；明确取消则撤销。

设置页可查看所需浏览器资源下载进度。下载失败给重试/选择已安装浏览器，不让普通用户复制复杂命令；开发模式的解包调试路径不作为发布 UX。

## 旅行主页面
```text
本次旅行：原始需求 / 已确认条件 / 暂定条件 / 未确定条件
研究状态：小红书读取 N 篇、其他来源 N 个、缺口、暂停原因

对话                          粗略攻略卡 / 每日行程
                              地图（高德，未接入时明确提示）
                              预算：已知范围 + 未知项
```

首轮卡片每张固定展示：路线名称、片区顺序、代表体验、建议天数范围、适合的玩法取向、交通依赖、主要舍弃项、证据按钮。地图未配置时可先展示文字顺序，但不能用想象坐标画“高德路线”。

问题区只显示下一两个重要选择，例如“你更想集中玩一个片区，还是多地串联？”同时允许自由输入。答“没想好”展开带取舍的比较，不标红必填。

## 改选
卡片支持必去/感兴趣/这次不去；已确认版和预览版有明显区分。用户取消 C、加入 B/D 后，展示：新增/取消、交通和时间变化、预算变化、受影响的酒店、冲突和未核实项。按钮“采用这一版”“返回原版”。不在用户点击确认前覆盖。

活动无法安排时显示原因链条，例如“可用540分钟，当前预计760分钟，超出220分钟”，并给出删减/延长/改变交通的选项。不能只写“AI认为不合适”。

## 资料与价格状态
资料徽标：仅候选信息、已读正文、部分图像已读、信息不完整、旧资料待核实。
报价徽标：查到报价、估算、历史参考、未开售、售罄、未知、已支付。
未确认数据不能使用与已确认同样的绿色成功态。

## 失败状态
来源不能获取：清楚展示小红书研究未完成；可以查看其他来源草稿，但不能悄悄隐藏失败。
请求预算耗尽：显示已读取数量和还缺什么；按钮“先用当前结果”“追加有限研究”；按钮背后不默认无限预算。
应用关闭/关机：下一次启动显示可恢复任务；不展示“离线期间仍在研究”。

## 可访问性与移动视图
键盘可操作按钮、焦点恢复、加载状态屏幕阅读说明；二维码提供“打开官方登录窗口”的操作替代，不把二维码解释文本伪装成可扫码替代品。

手机布局支持阅读导出的攻略和响应式页面，但首版不开放不安全 LAN 访问或云端扫码链路。远程跨设备连接另立安全设计；不可为了手机访问直接把服务绑定 0.0.0.0。
