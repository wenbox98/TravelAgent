# T06.1 私人本地缓存与真实 G1 验收记录

## 结论与范围

**A 数据策略、B 缓存实现：离线 PASS。C 真实 G1：BLOCKED / NOT PASS。G0 沿用此前已接受的 PASS。**

本轮按当前用户新要求实现 PRIVATE_LOCAL_RESEARCH，暂不公开发布或支持多用户。只持久化实际精读的少量来源，默认 PERSISTENT；不建立公共数据集、不向自有服务端上传、不把私人用途写成作者/平台授权。权利 basis 仍是 UNKNOWN。尚未实现 embedding 或向量库。

真实验收启动请求先后两次被执行环境自动审批拒绝，均发生在进程执行前。第二次请求已加入外发输入缩减，审批仍认为普通正文可能含未识别的姓名、个人经历等信息，要求明确确认这些内容可发送到具体外部目的地 DeepSeek。它是执行环境的审批结论，不是新增的仓库 SourcePolicy 门槛，也不构成必须取得作者授权的法律判断。本轮没有核实服务商部署位置或跨境传输路径。

两次拒绝均不是实站尝试；没有启动浏览器、登录、搜索、详情或真实模型请求。未通过其他工具或拆分流程绕过拒绝。`.local/t06.1-private/attempt.json` 与 `research.sqlite3` 均未创建，访问预算没有消耗。真实内容持久化、人工逐条 grounding、真实独立进程恢复仍待执行，不能用离线结果替代。

## 实现与契约变更

| 文件 / 符号 | 最终行为 |
|---|---|
| `domain/source_policy.py`：private_policy、scope_allowed、SENSITIVE_RESEARCH_TEXT | 明确私人用途、绑定本地范围、默认长期保留；凭证型文字先于模型和持久化被拦截 |
| `contracts/domain.schema.json`：SourcePolicy、SourceContent、SourceBodyBlock | 分离权利依据与私人用途；定义正文、规范文本、块、hash、时效、图片状态；不增加公开原文 API |
| `contracts/migrations/005_private_source_content.sql`、Database | SQLite v5：source_contents、source_body_blocks、research_run_contents；同步数据库契约和 OpenAPI 边界说明 |
| `research/content_store.py`：SourceContentStore.put/load、validate_content、audit_grounding | 只接收已预留 DETAIL、身份匹配、FULL/PARTIAL 的资料；再次校验正文/块/hash；同 hash 复用，变化新增版本；旧 Evidence 不被覆盖 |
| `research/store.py`：save_detail、lookup、clear_research_cache | 正文与证据事务提交；connect 前查缓存；按 scope 清研究资料，不依赖 ProfileStore/disconnect |
| `research/service.py`、`persistence/repositories.py` | 保留现有预算、去重、早停、revision、策略撤销和账号范围检查；允许显式私人策略的派生证据复用 |
| `research/model_input.py`、EvidenceExtractor.extract | 外部模型每篇最多 6,000 字/120 块；省略链接、邮箱、手机、证件号、联系方式/住址标签所在整块；原块号/offset 不改变；拒绝模型引用未发送块 |
| `research/private_smoke.py`：run_live、ObservedExtractor | 一次具名耐久账本，固定最多 1 search / 3 detail，OBSERVE_ONLY；模型失败停止继续读取；不把 fallback 判为真实通过 |
| `research/live.py`：LiveResearchReader.connect | 正常登录提示可在同一 BrowserSession 等待；验证/限制停止；正常 close 保留 profile |
| `research/reporting.py`：render_private_report | 根据已定位证据输出方向、短引文、未知项及最多两个后续问题，不固定凑三个方向 |
| `tools/private_cache_probe.py`：probe | 独立进程恢复正文、Evidence、Coverage、报告；socket audit hook 禁止网络，reader 禁止 connect/search/detail；验证五天/不自驾增量 |

raw_text、dom_text、normalized_text 分离；记录 normalization_version、retrieved_at、published_at、completeness、body origin 和 hash。7_DAYS / 30_DAYS 从首个快照时间计算，读取前逻辑清理过期正文；相同内容再次取得不会延长期限。PERSISTENT 保留到显式删除；EPHEMERAL 不保存原文，派生证据仍遵守独立策略。

不长期保存原始图片，仅 image_count / IMAGE_NOT_ANALYZED；不提取评论。认证材料仅在专用浏览器 profile 管理，不进入研究库、模型或 Git。外发只含正文块 index/text/origin/truncation_risk、完整度及研究缺口，不附作者、账号、标题、source ID、图片或页面链接。规则筛选不是完整匿名化证明，省略内容形成 MODEL_INPUT_MINIMIZED 缺口。
