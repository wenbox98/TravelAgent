# T06.1 私人本地缓存与真实 G1 验收记录

## 结论与范围

**真实 G1：FAIL。正常登录复用、搜索、详情读取成功；首次真实模型提取失败并降级，验收立即停止。G0 保持此前已接受的 PASS。**

私人缓存实现及离线回归保持通过；本次真实失败路径未成功持久化正文。项目仍为 PRIVATE_LOCAL_RESEARCH，不公开发布或支持多用户；权利 basis 仍是 UNKNOWN。用户本次明确批准必要正文经现有过滤发送 api.deepseek.com，不再以版权或公开发布策略阻塞本次测试。

历史上两次执行前自动审批拒绝均未消耗实站预算，已记录在 `0fc9176`。用户的新明确批准解决了该确认项。随后首次启动发现独立脚本缺少 sidecar 模块路径，返回 LOCAL_SETUP_ERROR；当时账本、数据库和浏览器仍未创建，修复后才开始唯一一次实际站点实验。

实际执行 1 search / 1 detail / 1 provider 调用后，模型未得到合格结果。入口收到 LOCAL_EXTRACTIVE 降级，记录 LIVE_LLM_EXTRACTION_FAILED，停止继续读第二篇。已正常关闭浏览器并保留 profile；没有重搜、重读、模型自动重试、额外连通性探测或重置账本。`.local/t06.1-private/attempt.json` 和研究 SQLite 保留且被 Git 忽略。

当前模型错误统一映射为 LLM_UNAVAILABLE_OR_INVALID，未记录 HTTP 状态或可区分的传输/JSON/schema 原因；不能断言是 30 秒超时、模型服务故障或 schema 错误。配置超时为 30 秒，但这不是本次失败根因的证明。

| `research/model_input.py`、EvidenceExtractor.extract | 外部模型每篇最多 6,000 字/120 块；省略链接、邮箱、手机、证件号、联系方式/住址标签所在整块；原块号/offset 不改变；拒绝模型引用未发送块 |

| `scripts/private_research_smoke.py`、`test_standalone_entry_loads_sidecar_without_pytest_pythonpath` | 修正独立 CLI 的 sidecar 导入路径；无 pytest PythonPath、无模型配置且禁止网络的子进程回归 |

raw_text、dom_text、normalized_text 分离；记录 normalization_version、retrieved_at、published_at、completeness、body origin 和 hash。7_DAYS / 30_DAYS 从首个快照时间计算，读取前逻辑清理过期正文；相同内容再次取得不会延长期限。PERSISTENT 保留到显式删除；EPHEMERAL 不保存原文，派生证据仍遵守独立策略。

不长期保存原始图片，仅 image_count / IMAGE_NOT_ANALYZED；不提取评论。认证材料仅在专用浏览器 profile 管理，不进入研究库、模型或 Git。外发只含正文块 index/text/origin/truncation_risk、完整度及研究缺口，不附作者、账号、标题、source ID、图片或页面链接。规则筛选不是完整匿名化证明，省略内容形成 MODEL_INPUT_MINIMIZED 缺口。
