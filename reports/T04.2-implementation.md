# T04.2：阶段限定的文字资源策略

本阶段在 T04.1 基线 `d3645464bfb5a6921bbca137faf37cb27334f35e` 后，由用户授权与 T05 一起实现。功能默认 OBSERVE_ONLY；真实执行结果另见后续 T05 Smoke 报告，不以离线 Fake 代替实测。

## 变更

- `resource_policy.py`：ResourcePolicy / ResourcePolicyController，在 SEARCH/DETAIL 期间只阻止 image、media、font；保留 document/script/stylesheet/xhr/fetch/other，不封锁 analytics 域名。没有 stealth、代理、UA 或 Service Worker 设置修改。
- `live_page.py`：LiveBrowserBackend 接收显式策略，退出恢复自有 handler，失败锁存关闭优化；支持 SEARCH/SEARCH_2/SEARCH_3、DETAIL_1～6 安全窗口。backend 不发起降级重导航。
- `live_observability.py`：8 类请求、route attempted/blocked/continued/errors、各类 blocked 计数和缓存影响。abort 事件不从 total 扣除，未知 bytes 保持 null。
- 对应 `test_resource_policy.py`、`test_live_page.py`、`test_live_observability.py` 验证 LOGIN/idle 边界、类型白名单、handler 清理、异常和敏感 sentinel。

没有更改现有 HTTP/domain API 契约。只扩展内部统计，不启用生产默认优化。Playwright route 会影响 HTTP cache，Service Worker 拦截请求不保证经过 handler，故历史基线不可直接作严格百分比对比。
